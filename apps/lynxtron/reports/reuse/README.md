# T5-F2 dependency and physical-reuse report

`current.json` is the deterministic seven-screen report generated by:

```text
pnpm --filter @t3tools/lynxtron report:reuse
```

The report treats Electron/Web as the upstream product source. Its denominator
is every eligible Web production module in the selected graph and every
physical line in those modules. A Web module is reused only when the paired
Lynx graph reaches the same canonical realpath. Textually identical copies,
moves, and renames remain `EXCLUSIVE`; `.web` / `.lynx` siblings are `SPLIT`;
generated theme CSS is registered as `PATCHED`, not `SHARED`.

The Lynx resolver contract is read from a fresh
`rspeedy inspect --verbose -m production` result. The report records its exact
aliases, extension order, conditions, package fields, main files, symlink
policy, and a deterministic fingerprint. Third-party packages, tests,
generated files, the host process, and registered hard islands are outside the
eligible source denominator.

## Fixed boundary

`scripts/reuse-boundaries.json` owns all screen roots, exclusions, hard islands,
and generated pairs. `scripts/reuse-boundaries.baseline.json` records the
reviewed SHA-256. The report command fails before graph construction whenever
that hash changes, so an exclusion or boundary edit cannot silently improve the
percentage.

The focused fixture covers:

- `.tsx`, `.web.tsx`, and `.lynx.tsx` resolution;
- exact `$` primitive aliases;
- conditional package subpath exports;
- byte-identical copied-and-renamed files;
- generated Web/Lynx CSS;
- package and source-file symlinks with canonical realpath identity.
